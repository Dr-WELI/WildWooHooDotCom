5 · The wordmark

The new font system in action. Capital W and H stay as custom geometric paths — same DNA as the logo W (thick lines, well-spaced, angular zig-zag). Lowercase i, l, d, o now flow in Caveat Bold — a handwritten font that pairs structured caps with personal, expressive writing. 7 · The font system

The logo W is a custom-drawn glyph in a style I'd call "geometric monoline display" — uniform thick stroke, no contrast variation, sharp angular vertices, round line caps and joins, well-spaced like a zig-zag. The closest available free font that carries this DNA is Big Shoulders Display (Patric King & Production Type, distributed by Google Fonts) — heavy weight, narrow proportions, sharp angular geometry. Use it everywhere the brand needs heavy display type: presentation titles, hero headlines, large labels, posters. Pair it with Caveat for handwritten emphasis. Both are already loaded on this page — see the samples below.

The locked font stack

What goes where

Token Family Use
--font-mark Custom SVG paths (logo W / H) The wordmark caps. Drawn glyphs, not a font — exists only as SVG.
--font-display Big Shoulders Display (700 / 800 / 900) All large display type: hero headlines, presentation titles, poster type, big labels. Closest free match to the logo W's geometric monoline DNA.
--font-script Caveat (500 / 700) Handwritten lowercase, italic emphasis, captions under photography, signature lines, "personal" voice moments.
--font-serif Libre Baskerville (400 / 700) Editorial section headlines, long-form body that wants to feel like a magazine. Already in brand.
--font-sans Montserrat (400 / 500 / 700) Body copy, navigation, UI, labels. Already in brand.

Installation. Both Big Shoulders Display and Caveat are free Google Fonts. Add this to <head> of any page or presentation HTML, and they're available immediately: <link href="https://fonts.googleapis.com/css2?family=Big+Shoulders+Display:wght@700;800;900&family=Caveat:wght@500;700&display=swap" rel="stylesheet">. For PowerPoint / Keynote / Google Slides, download the TTF files from fonts.google.com/specimen/Big+Shoulders+Display and fonts.google.com/specimen/Caveat and install them on your system.

8 · The rule

Never together. The mark is for headers, favicons, app tiles, social profiles, watermarks, stickers, OG squares. The wordmark is for the splash hero, footers, t-shirts, posters, business cards, decks. They share DNA but are never seen side-by-side. If a context needs both "an icon and a name", use the wordmark — its custom W already plays the role of a mark.
